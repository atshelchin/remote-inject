### Detailed Description
```
Remote Inject Bridge lets you use any web3 DApp in your desktop browser while signing transactions with your mobile wallet — no MetaMask or browser extension wallet required.

How it works:
1. Install this extension and open the popup (or side panel).
2. Connect to a relay server (default: remote-inject.awesometools.dev, or self-hosted).
3. Scan the QR code with your mobile wallet's built-in DApp browser.
4. The DApp and your mobile wallet are now bridged — all signing requests are forwarded to your phone in real time.

Features:
• Works with any EIP-1193 compatible DApp
• Supports MetaMask Mobile, Trust Wallet, OKX Wallet, and other mobile wallets with built-in DApp browsers
• Side panel mode — keep the bridge open while browsing
• Auto-reconnect — bridge restores automatically when you return to a DApp
• Activity log — see recent signing requests and their status
• Light / dark mode follows the current webpage's theme
• Bilingual UI (English / 中文)
• Open source — relay server can be self-hosted

Permissions explained:
• storage — saves your relay server URL and active session so you don't need to re-scan each visit
• tabs — reads the current page's color scheme to match the popup theme
• sidePanel — enables the side panel mode
• offscreen — maintains the SSE relay connection in the background while you browse

Source code: https://github.com/atshelchin/remote-inject
```

### 详细描述
```
Remote Inject Bridge 让你在桌面浏览器中使用任意 Web3 DApp，同时用手机钱包完成签名操作，无需 MetaMask 或其他浏览器钱包插件。

使用方式：
1. 安装本插件，打开弹窗或侧边栏。
2. 连接到中继服务器（默认：remote-inject.awesometools.dev，也支持自部署）。
3. 用手机钱包内置的 DApp 浏览器扫描二维码。
4. DApp 与手机钱包完成桥接，所有签名请求实时转发到手机。

功能特点：
• 兼容所有支持 EIP-1193 标准的 DApp
• 支持 MetaMask Mobile、Trust Wallet、OKX Wallet 等带内置 DApp 浏览器的移动端钱包
• 侧边栏模式 — 浏览网页时保持桥接面板常驻
• 自动重连 — 回到 DApp 时自动恢复连接
• 操作日志 — 查看最近的签名请求及状态
• 亮色/暗色模式跟随当前网页主题自动切换
• 中英双语界面
• 开源 — 中继服务器支持自部署

权限说明：
• storage — 保存中继服务器地址和会话信息，避免每次重新扫码
• tabs — 读取当前页面配色方案以匹配弹窗主题
• sidePanel — 启用侧边栏模式
• offscreen — 在后台维持 SSE 中继连接，切换标签页时不断线

源代码：https://github.com/atshelchin/remote-inject
```
